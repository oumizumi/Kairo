# uomap

Student tool for the University of Ottawa.

- **Schedule builder** - search every uOttawa course, detect conflicts, build a weekly timetable
- **uoguessr** - guess where on campus each photo was taken, solo or multiplayer
- **Student opportunities** - TA postings, scholarships, and academic opportunities

> Independent project. Not affiliated with the University of Ottawa.

## Stack

Next.js 15, TypeScript, Tailwind CSS, Supabase, Netlify

## Dev

```bash
cd frontend
npm install
npm run dev
```

Runs at `http://localhost:3000`.
